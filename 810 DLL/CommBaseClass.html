Ｏｐｅｎ（ＢｙＶａｌ　ｐａｒａｍ　Ａｓ　Ｓｔｒｉｎｇ）　Ａｓ　Ｉｎｔｅｇｅｒ

機能：通信ポートを開きます。

引数：pram
　　GPIB(通測NI社製)
　　　アドレス　=　”１”～”３２”
　　RS232C(通測)　=　”ポート番号，ボーレート，ビット仕様，ハンドシェーク”
　　　ポート番号
　　　　COM1　=　0
　　　　COM2　=　１
　　　　COM3　=　2
　　　　COM4　=　3
　　　ボーレート
　　　　1200　=　0
　　　　2400　=　1
　　　　4800　=　2
　　　　9600　=　3
　　　　19200　=　4
　　　　38400　=　5
　　　　57600　=　6
　　　ビット仕様
　　　　ストップビット8，ノンパリティ，ストップビット1　=　0
　　　　ストップビット7，奇数パリティ，ストップビット1　=　1
　　　　ストップビット7，偶数パリティ，ストップビット1　=　2
　　　ハンドシェーク
　　　　無し　=　0
　　　　XonXoff　=　1
　　　　CTS-RTS　=　2
　　Ether(通測)　=　”サーバー名，ユーザー名，パスワード”
　　　サーバー名　=　通測の測定器のサーバー名，又は、IPアドレス
　　　ユーザー名　=　ユーザー名
　　　パスワード　=　パスワード
　　　※ユーザー名，パスワードの指定が無くても、”，”の省略は不可
　　USB(通測)
　　　アドレス　=　”1”～”127”

戻り値：
　　COMM_OK　=　正常終了
　　COMM_ERROR_OPEN　=　オープンエラー
